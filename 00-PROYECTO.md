# Sistema Mis Oficios

## Nombre

Mis Oficios

## Objetivo

Sistema web para la administración, envío, recepción y seguimiento de oficios electrónicos entre departamentos de un Gobierno Municipal.

El objetivo principal es eliminar completamente el uso de oficios impresos, sustituyéndolos por documentos digitales con validez administrativa.

Cada oficio podrá:

- ser enviado electrónicamente
- ser leído por el destinatario
- generar acuse de lectura
- solicitar respuesta
- recibir respuesta
- adjuntar documentos PDF
- conservar historial
- generar reportes
